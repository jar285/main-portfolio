## QA Deviations

1. **Tailwind v4 → v3 downgrade.** Next.js 16 `create-next-app` installs
   Tailwind v4 (`@tailwindcss/postcss`). Downgraded to Tailwind v3.4.19 with
   traditional `tailwindcss` + `autoprefixer` PostCSS pipeline per the tech
   stack decision in `agent.md`. This required replacing `@import "tailwindcss"`
   in `globals.css` with `@tailwind` directives and rewriting `postcss.config.mjs`.

2. **ESLint config uses `eslint-config-next` instead of standalone plugins.**
   Sprint doc Task 4 suggested installing `@eslint/js`, `typescript-eslint`,
   `eslint-plugin-react`, `eslint-plugin-react-hooks` separately. The generated
   `eslint-config-next` already bundles these via `core-web-vitals` and
   `typescript` presets in flat config format. Using the bundled config is
   simpler and avoids version conflicts. `eslint-config-prettier` and the
   `no-explicit-any` override were added on top.

3. **shadcn/ui initialized manually.** Instead of running `npx shadcn@latest init`
   (which may overwrite files), `components.json` was created manually with
   correct paths. This avoids the overwrite risk noted in sprint doc QA
   observation #3.

4. **Scaffold created in temp directory then moved.** Because `agent.md` already
   existed in the portfolio directory, `create-next-app` was run in a temp
   directory and files were copied over. This required a clean `npm install`
   after the copy to fix broken symlinks in `node_modules/.bin/`.

5. **Leftover create-next-app assets removed.** Default SVGs (`file.svg`,
   `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`) were deleted from
   `public/`. `favicon.ico` retained for replacement in `design-system`.
